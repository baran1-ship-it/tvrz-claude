# Kresby Puchartu od třetích stran

## figely_dali_2023_puchart.jpg
- Perokresba A3, podpis „DALI FIGELY 23“, zveřejněno na Facebooku (reel 1557412185599588) s popisem
  „Hrad Puchart, před obléháním hradu za Matyáše Korvína“. Snímek obrazovky od Míši 9. 11.
- Autor ani zdroje kresby na webu nedohledány (hledání 9. 11.) → **KRESBA (umělecká rekonstrukce), ne DOLOZENO**.
- Datace: „před obléháním za Korvína“ = varianta zániku 1475 (ancient-history-sites.com); archeologický atlas spojuje zánik
  s dobytím Potštátu koncem 14. stol. (1394). Hra je v roce 1393 → kresba může ukazovat pozdější stav.
- Shoda s modelem: dvojhrad, zadní hrad na skále s vysokou budovou a strmými střechami, dlouhý most přes průrvu, přední
  hrad s obloukovou hradbou na valu. Navíc: stupňovitá zástavba zadního hradu po skále, most stoupá od předního hradu.
