Míša 13. 11.: „takhle by měly vypadat všechny toky“ – platí pro všechny potoky i Veličku.

Společné: voda nikde není rovná deska – hladinu lámou kameny, mění se šířka a hloubka (tůň – peřej), na kraji mokré kamení
a štěrk, vegetace převisá do vody.
