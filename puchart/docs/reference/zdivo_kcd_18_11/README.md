# Předloha zdiva (Míša 18. 11.: „tady kámen vypadá jako kámen a zeď jako zeď“) – KCD 1/2 a podobné
Co z nich plyne pro plán F (docs/rozpracovane/plan_z_reserse_17_11.md):
1. Zeď z dálky je KLIDNÁ: světle šedá/béžová, jemná drobná struktura lomového kamene, malta skoro v rovině, žádný
   kontrastní „mramor“ ani velké skvrny (02, 04, 05, 09). Náš kámen má příliš velký kontrast a měřítko – tapeta.
2. Kontrast a reliéf jen tam, kde je v reálu: nároží a ostění z velkých tesaných kvádrů (01 podezdívka, 07, 08, 11),
   patka a koruna, otlučená omítka s vykukujícím kamenem (09 kostel, 10 brána), cimbuří s kamennými hranami.
3. Omítka (vápenná) na palácích a branách – bílá/šedá plocha, kámen jen v místech, kde opadala (09, 10, 11, 12).
4. Koruna cimbuří a nároží mají skutečnou geometrii (kvádry vystupují), ne jen texturu (07, 08).
5. Barva: studená šedá s teplým nádechem, žádné syté oranžové/hnědé tóny (naše louče barví kámen do oranžova).
